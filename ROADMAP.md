# Roadmap

## 0.1.1.x — lightweight MVP
- Search strategy/query compiler
- Commercial-export import
- SQLite canonical model
- EPO OPS bibliographic retrieval
- Family merge, technical classification, LLM annotation loop, core-patent scoring
- JSON/Markdown/Excel/HTML reports

## 0.2.0.x — connector layer
- USPTO Open Data / Patent Public Search helpers
- KIPRIS+ connector
- WIPO/PATENTSCOPE export helpers
- Optional licensed IncoPat / Derwent API adapters
- Query partition planner and resumable retrieval

## 0.3.0.x — patent-family/legal intelligence
- DOCDB simple family + INPADOC extended family
- Legal-event normalization
- Applicant/assignee normalization and aliases
- Citation network and jurisdiction coverage matrix

## 0.4.0.x — claims/FTO
- Independent-claim element extraction
- Claim overlap matrix
- Evidence-linked technical route graph
- FTO pre-screening by jurisdiction and legal status

## 1.0.0.x — stable professional release
- Stable schema/migrations
- Connector contract and test corpus
- Reproducible project manifests
- Full audit trail and report provenance
